## Cómo usar esta documentación

> **Nota:** Esta guía es de carácter informativo y orientativo. Para casos con implicancias legales específicas, siempre consulta directamente con un notario público colegiado.

Cada sección de proceso sigue una estructura consistente:

1. **Descripción del acto** — qué es y cuándo se necesita
2. **Base legal** — norma que lo regula
3. **Requisitos documentales** — lista descargable
4. **Flujo del procedimiento** — diagrama y pasos ordenados
5. **Costos estimados y plazos** — rangos referenciales
6. **Preguntas frecuentes** — casos de duda comunes
